## 怎麼重跑

在解壓縮後的套件根目錄執行：

```bash
python3 -m unittest discover -s tests -v
```

測試會建立並清理暫存目錄，以假的回應攔截所有 API 操作。重新導向測試使用真正的 urllib handler 流程配上離線 transport，確認不會向第二個位置轉送憑證。Git 範圍與安裝行為使用暫存專案驗證，而非只檢查程式碼文字。

沒有使用你的 API key，沒有呼叫 TypeSafe 或 Claude 的付費模型，也沒有在你的實際專案進行安裝。套件中的 `last-decision.json` 是不含原始 prompt 的初始中繼資料，並非真實 Jev 判斷結果。
