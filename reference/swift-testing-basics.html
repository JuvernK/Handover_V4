Swift Testing basics

The smallest useful syntax and workflow for a focused unit test.

Minimal test

import Testing
@testable import Handover_V4

@Test
func behaviourBeingChecked() {
    // Arrange
    let input = ...
    let expected = ...

    // Act
    let actual = codeUnderTest(input)

    // Assert
    #expect(actual == expected)
}

What each piece means

  • import Testing makes Swift Testing APIs available.
  • @testable import Handover_V4 exposes the app module’s internal declarations to its test target.
  • @Test tells the test runner to discover the function.
  • #expect(condition) records a failure when the condition is false, then allows the test to continue.
  • #require(condition) stops the current test when a value is required for the remaining checks.

Behaviour-first naming

Prefer selectedAbbreviationExpandsInline() over testGlossary(). The name should tell you the rule that broke.

Run tests

  • Xcode: open the Test navigator with ⌘6, then use the play button beside one test.
  • Xcode: use Product → Test or ⌘U for the scheme.
  • Terminal: run the project’s documented xcodebuild … test command with a concrete visionOS simulator destination.
