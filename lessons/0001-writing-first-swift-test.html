Lesson 1 · About 10 minutes

Turn one behaviour into a test

Use the abbreviation feature to learn the smallest complete Swift Testing loop: arrange the situation, act on the code, and assert the result.

Tangible win By the end, you will be able to explain and write a focused test that proves: selecting CRRT appends its full term inline while preserving CRRT.

First: what is a test case?

A test case is a small executable example of one required behaviour. It supplies known input, calls your production code, and checks the observed result against an expected result.

The Handover_V4Tests target is a separate test product. That is why adding the first tests changed project.pbxproj: Xcode had to record the target, its dependency on the app, and how the test bundle is built.

1 · ArrangeCreate the source text, stable identity, selection, and expected output.
2 · ActCall the public behaviour boundary you want to verify.
3 · AssertCompare the actual result with the requirement.

Read the real Handover test

import SwiftUI
import Testing
@testable import Handover_V4

@Test
func selectedApprovedAbbreviationExpandsInline() {
    // Arrange
    let textID = "plan.item.p5-plan-1.task"
    let text = "Continue CRRT overnight"
    let selection = AbbreviationSelection(
        textID: textID,
        glossaryEntryID: "crrt",
        occurrenceIndex: 0
    )
    let expected =
        "Continue CRRT (Continuous renal replacement therapy) overnight"

    // Act
    let rendered = ClinicalAbbreviationGlossary.attributedString(
        for: text,
        textID: textID,
        selection: selection,
        baseColor: .primary,
        abbreviationColor: .accentColor
    )

    // Assert
    #expect(String(rendered.characters) == expected)
}
The key design choice This test checks observable text output. It does not know how the glossary scans the string internally. That lets the implementation be refactored without rewriting the test, as long as the clinical behaviour remains correct.

Your first writing exercise

Now write—not copy—a test for this rule:

An unknown term such as XYZ remains unchanged.

Use this scaffold. Fill only the four blanks:

func unknownTermRemainsPlain() {

Run it in Xcode

  1. Open ClinicalAbbreviationExpansionTests.swift.
  2. Add the test inside ClinicalAbbreviationExpansionTests.
  3. Click the diamond/play control beside the test, or open the Test navigator with ⌘6.
  4. A green result means the behaviour matched. A red result is useful evidence: read the values shown by #expect.
