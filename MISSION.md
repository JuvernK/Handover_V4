# Mission: Swift Testing for Handover V4

## Why
Learn to write and run Swift tests independently for Handover V4, so feature
behaviour can be verified and bugs caught before changing the app.

## Success looks like
- Turn one behaviour requirement into a focused Swift Testing test
- Explain the Arrange–Act–Assert structure in an existing test
- Run one test or the full test target in Xcode and interpret the result
- Use a failing test to guide a small implementation change

## Constraints
- Learn through short lessons using real Handover V4 code
- Focus on the visionOS project’s existing Swift Testing target
- Introduce one testing concept at a time

## Out of scope
- UI automation, performance testing, and code-coverage targets for now
- Advanced mocking or continuous-integration configuration for now
