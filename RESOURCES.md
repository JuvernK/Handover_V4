# Swift Testing Resources

## Knowledge

- [Apple: Adding tests to your Xcode project](https://developer.apple.com/documentation/xcode/adding-tests-to-your-xcode-project)
  Primary guide to test targets, test files, `@testable import`, and the
  Arrange–Act–Assert structure. Use for the end-to-end Xcode workflow.
- [Apple: Defining test functions](https://developer.apple.com/documentation/Testing/DefiningTests)
  Primary Swift Testing syntax reference for `import Testing`, `@Test`, suites,
  concurrency, and actor isolation. Use when declaring a test.
- [Apple: Expectations and confirmations](https://developer.apple.com/documentation/Testing/Expectations)
  Primary reference for `#expect` and `#require`. Use when deciding how a test
  should check its result.
- [Apple: Swift Testing overview](https://developer.apple.com/xcode/swift-testing/)
  High-level overview of Swift Testing’s capabilities and Xcode integration.
  Use when exploring what to learn after the basics.

## Wisdom (Communities)

- [Swift Forums: Swift Testing](https://forums.swift.org/c/development/swift-testing/103)
  Official Swift community category with framework contributors and
  practitioners. Use for unusual behaviour, concurrency questions, and API
  design discussions after checking the primary documentation.
